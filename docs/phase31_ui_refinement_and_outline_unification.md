# Phase 31: サイドバー・アウトラインUIの洗練とフラッシュ防止

## 概要
サイドバーのアイコン表示の制御（ホバー時のみ表示）、起動時のチラつき（フラッシュ）の排除、およびアウトラインセクションの文言統一を行い、アプリ全体の完成度とクリーンな印象を向上させました。

## 修正内容

### 1. アクションボタンのホバー表示制御とフラッシュ防止
- **ホバー表示の導入**: エディタおよびワークスペースセクションのアクションアイコンを、通常時は非表示（`opacity: 0`）にし、マウスホバー時のみ表示されるように変更しました。
- **起動時の表示抑制**: ワークスペース選択前のアクションボタンに初期状態で `hidden` クラスを付与し、JS実行前の起動直後にアイコンが一瞬表示される現象を完全に防止しました。
- **誤操作の防止**: アイコンが非表示の状態ではクリックイベントを受け付けないよう `pointer-events: none` を適用しました。

### 2. アウトライン表示の統一と文言更新
- **VSCode 風メッセージへの統一**: 見出しがない場合の文言を「アクティブなエディターはアウトライン情報を提供できません。」に統一しました。
- **全状態での同期**: アプリ起動直後（ファイル未選択時）と、ファイルを開いたが見出しがない場合の両方で同じメッセージが表示されるようにしました。
- **スタイルの統一**: 薄い灰色かつイタリック体のスタイルが全ての状態で確実に適用されるよう、CSS と HTML のクラス名を同期しました。

### 3. ステータスバーのデザイン復元
- **ネオブルータリズム・スタイルの復元**: アプリ下部に、テーマカラーの背景と太い枠線を持つ高品質なステータスバーを復元しました。
- **リアルタイム更新**: 現在開いているファイルの行数、単語数、文字数が編集に合わせて即座に反映されるように実装しました。

## 成果
通常時は視覚ノイズが極めて少なく、必要なときだけ機能が顔を出す洗練された執筆環境が整いました。また、起動から編集、情報の確認に至るまで、ユーザー体験を損なう「チラつき」や「文言の不一致」を排除し、プロフェッショナルな道具としての信頼性を高めています。
