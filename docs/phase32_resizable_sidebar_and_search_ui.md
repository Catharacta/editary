# フェーズ 32: サイドバーのリサイズ機能と検索UIの専門化 ✅

## 目標
サイドバーの幅をユーザーが自由に変更できる「リサイズ機能」の実装と、グローバル検索UIの視認性向上を目指す。

## 実施内容

### 1. サイドバー・リサイズ機能の実装
- **LayoutManager.ts の新設**: マウスイベント（mousedown, mousemove, mouseup）を監視し、動的にサイドバー幅を変更するロジックを TypeScript で実装。
- **永続化**: `localStorage` を使用し、ユーザーが設定したサイドバーの幅を次回起動時も維持するように。
- **リサイズハンドル**: ネオ・ブルータリズムの 3px の力強い境界線の上に、6px の判定領域を持つ透明なリサイザーを配置。

### 2. レイアウトの Flexbox 化
- **app-container の刷新**: 従来の `grid-template-columns` による固定的なグリッドレイアウトから、動的なリサイズに強い `flex` レイアウトへ移行。
- **整合性の確保**: アクティビティバーは固定幅、エディタ領域は `flex: 1` で残りの領域を自動的に専有する構造に整理。

### 3. グローバル検索・置換 UI の改善
- **プレースホルダーの短縮**: 「Search / Replace」および「検索 / 置換」に表記を簡略化。
- **重なりの解消**: 入力欄の文字とオプションアイコンが被る不具合を、テキストの短縮とレイアウト調整によって解決。
- **アクセシビリティ**: 検索パネルの表示/非表示時のショートカット(`Ctrl+F`, `Ctrl+H`)の安定動作を確保。

- [x] 検索パネルの入力欄が読みやすく、アイコンと干渉しないこと。
