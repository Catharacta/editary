# Editary - 開発ロードマップ

## フェーズ 1: プロジェクト基盤の構築 🏗️
> **目標**: ElectroBunプロジェクトを初期化し、開発環境を整備する

- [ ] ElectroBunプロジェクトを `bunx electrobun init` で初期化する
- [ ] React + Vite + TypeScript のフロントエンド環境をセットアップする
- [ ] pnpm で依存関係を管理する
- [ ] TailwindCSS を導入し、ネオブルータリズムのデザイントークンを定義する
- [ ] ElectroBun のフレームレスウィンドウ設定（カスタムタイトルバー用）
- [ ] `.gitignore` の設定
- [ ] ESLint / Prettier の設定

**完了条件**: `bun start` でElectroBunウィンドウが起動し、React画面が表示される

---

## フェーズ 2: コアエディターの実装 ✍️
> **目標**: Tiptapベースのリアルタイム Markdown エディターを実装する

- [ ] Tiptap エディターと依存パッケージをインストールする
- [ ] 基本的な Markdown 拡張機能を構成する
  - Document, Text, Paragraph, Heading (H1〜H6)
  - Bold, Italic, Strike
  - BulletList, OrderedList, ListItem
  - CodeBlock, Code (inline)
  - Blockquote, HorizontalRule
  - Link, Image
- [ ] Markdown 構文入力 → 即座にフォーマット変換される動作を実装する
  - `## ` → H2 見出し
  - `**text**` → 太字
  - `- ` → 箇条書き
  - `` `code` `` → インラインコード
  - `> ` → 引用
- [ ] エディター領域にネオブルータリズムのスタイルを適用する

**完了条件**: エディター上で Markdown を入力するとリアルタイムで装飾が適用される

---

## フェーズ 3: IPC通信とファイルシステム連携 📁
> **目標**: Bun (メインプロセス) と React (Webview) 間のファイル操作を実装する

- [ ] ElectroBun の IPC チャンネルを設計・実装する
- [ ] `openFolder`: OS のネイティブフォルダ選択ダイアログ
- [ ] `readDirectory`: `.md` ファイル一覧の再帰的取得
- [ ] `readFile`: ファイル内容の読み込み
- [ ] `writeFile`: ファイル内容の保存（上書き保存 & 新規保存）
- [ ] `createFile`: 新規 `.md` ファイルの作成
- [ ] エラーハンドリング（アクセス権限、ファイル競合など）

**完了条件**: Webview から Bun の IPC を通じて `.md` ファイルの CRUD 操作ができる

---

## フェーズ 4: UI の組み立て 🎨
> **目標**: ネオブルータリズムのサイドバー、タイトルバー、レイアウトを実装する

- [ ] グローバルレイアウト (サイドバー + タイトルバー + エディター) の構築
- [ ] カスタムタイトルバーの実装（最小化、最大化、閉じるボタン）
- [ ] ネオブルータリズムのサイドバーコンポーネント
  - フォルダ/ファイルツリーの表示
  - フォルダの展開/折りたたみ
  - アクティブファイルのハイライト
  - ファイルクリック → エディターにロード
- [ ] ファイル切り替えロジック（未保存変更の検出と警告）
- [ ] キーボードショートカットの実装
  - `Ctrl+S`: 保存
  - `Ctrl+O`: フォルダを開く
  - `Ctrl+N`: 新規ファイル
  - `Ctrl+B`: サイドバーの表示/非表示
- [ ] サイドバーのリサイズ機能

**完了条件**: フォルダを開き、ファイルを選択・編集・保存できる完全なワークフローが動作する
