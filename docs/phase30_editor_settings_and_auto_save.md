# Phase 30: エディタ設定の拡張 (行番号表示・自動保存)

## 概要
エディタの利便性を向上させるため、設定画面に「行番号の表示」と「自動保存」の項目を追加し、それぞれの機能を実装しました。また、設定画面の UI レイアウトを調整し、レスポンシブな表示を確保しました。

## 実装内容

### 1. 行番号の表示 (Line Numbers)
- **CSS Counter による実装**:
  - `editor.css` にて `counter-reset` と `counter-increment` を使用し、`.ProseMirror` 内の各ブロック要素に対して行番号を自動付与。
  - ネオブルータリズム様式に合わせた太字・高コントラストなデザインを採用。
- **表示制御**:
  - 設定画面のトグルで即座に表示・非表示を切り替え可能。
  - **改善**: ファイルが一つも開かれていない状態、またはエディタがブランクの状態では行番号を非表示にするロジックを導入。

### 2. 自動保存 (Auto-save)
- **デバウンス処理**:
  - エディタの `update` イベントから 2 秒間のディレイ（デバウンス）を経て、変更を自動的にファイルへ書き込みます。
- **安全設計**:
  - 既にファイルパスが存在する既存ファイル（または一度保存したファイル）のみを対象とし、タイトル未設定（Untitled）のファイルに対して予期せぬ保存ダイアログが出るのを防いでいます。

### 3. 設定画面の UI 改善
- **レイアウトの適正化**:
  - 自動保存の説明文が長い場合にトグルスイッチが右端から押し出される問題を、Flexbox (`flex: 1`, `min-width: 0`) の調整によって解決。
  - 全てのトグルが右端で綺麗に整列するように修正。
- **永続化**:
  - `localStorage` を利用し、アプリの再起動後も設定（テーマ、行番号、自動保存）が維持されるようにしました。

### 4. デフォルト設定の適正化
- ユーザーの混乱を避けるため、初回起動時のデフォルト設定を以下の通りにしました。
  - **行番号**: オフ
  - **自動保存**: オフ

## 次回以降の課題
- **行番号のクリック操作**: 行番号をクリックした際にその行を全選択する、あるいはブックマークを付与する等の拡張。
- **保存ステータスの明示**: 自動保存が行われた瞬間にステータスバー等でフィードバックを出す仕組みの検討。
