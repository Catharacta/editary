# Phase 29: ワークスペース操作の完成とグローバル検索 (案)

## 概要
ファイルツリーでの直接的な操作（リネーム・削除）を VS Code 風にブラッシュアップし、プロジェクト全体を横断する「グローバル検索」への足がかりを築きます。

## 実装提案

### 1. ファイルツリー上での操作拡充
- **インラインリネーム**:
  - `F2` キーまたはコンテキストメニューから、今回実装したファイル作成時と同様のインライン入力で名前を変更できるようにします。
- **削除フローの改善**:
  - コンテキストメニューから即座に削除（またはゴミ箱へ移動）できるようにし、確認ダイアログの挙動を整理します。

### 2. グローバル検索 (Search in Files)
- **バックエンドの実装**:
  - `grep` （または `ripgrep` / Bun の `readdir` + `readFile` 巡回）による全ファイル検索 RPC を実装します。
- **フロントエンド UI**:
  - 左サイドバーに「検索パネル」を追加（または既存の検索パネルを拡張）し、ファイル名だけでなくファイル内コンテンツでの絞り込みを可能にします。

### 3. 操作性の向上 (Quick Open)
- `Ctrl + P` によるファイル名クイックオープン機能の実装。
