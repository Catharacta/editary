# Editary - 開発計画書

## プロジェクト概要

**Editary** は、ElectroBun (Bun + ネイティブWebview) を使用して開発する、Windows 11向け Typora風 Markdownエディターです。
ネオブルータリズムのデザインコンセプトを採用し、高速かつ軽量で、視覚的にも印象的なエディターを目指します。

## 技術スタック

| 項目                             | 選定技術                   | 選定理由                                     |
| -------------------------------- | -------------------------- | -------------------------------------------- |
| **デスクトップフレームワーク**   | ElectroBun                 | Bun + ネイティブWebview で超高速・軽量       |
| **バックエンドランタイム**       | Bun                        | ファイルI/O、IPC通信のメインプロセス         |
| **フロントエンドフレームワーク** | React + Vite               | リッチテキストエディターのDOM/状態管理に最適 |
| **言語**                         | TypeScript                 | 型安全な開発                                 |
| **エディターライブラリ**         | Tiptap (ProseMirrorベース) | ヘッドレスのためカスタムデザインが容易       |
| **CSSフレームワーク**            | TailwindCSS                | ネオブルータリズムのデザイントークン管理     |
| **パッケージ管理**               | pnpm                       | プロジェクト規約に準拠                       |
| **対象OS**                       | Windows 11                 | ターゲットプラットフォーム                   |

### VS Code風タブ管理と非同期保存
- インメモリキャッシュ (`cachedContent`) により、未保存状態のままでもタブを自由に切り替え可能
- タブ切り替え時にブロッキングダイアログが発生せず、開発体験を損なわない
- `writeFile` 成功時にサイドバーのファイルツリーが自動リフレッシュされる同期設計
- OSネイティブの `SaveFileDialog` と `FolderBrowserDialog` を PowerShell 経由で非同期実行
- **堅牢なMarkdown往復変換**: `turndown` ライブラリを採用し、WYSIWYG編集とMarkdown保存の整合性を確保

### ネオブルータリズム デザイン
- 太い境界線（3px以上）
- はっきりとした影（`box-shadow: 4px 4px 0px black`）
- 高コントラストの配色
- ボタンのクリック時に「押し込まれる」物理的エフェクト
- フラットながらインパクトのあるUI
- **絵文字・外部アイコンライブラリ（Lucide等）の不使用**: 汎用的なインラインSVGアイコンを用いたクリーンな実装
- **リッチなMDコンポーネント**: テーブルやタスクリストもネオブルータリズムのスタイルで統一

## MVP (最小限実行可能プロダクト) の機能要件

### 必須機能
1. **基本Markdownフォーマット**
   - 見出し (H1〜H6)
   - 太字、斜体、取り消し線
   - 箇条書きリスト / 番号付きリスト
   - コードブロック / インラインコード
   - 引用
   - 水平線
   - リンク / 画像
   - **テーブル (GFM対応)** [NEW]
   - **タスクリスト (チェックボックス)** [NEW]

2. **ファイル・フォルダ操作**
   - フォルダを開く（未選択時UIとネイティブダイアログ）
   - ディレクトリ作成 / ファイル作成
   - ファイルの読み込み / 保存（自動選択フォールバック対応）
   - 手動パス入力によるエッジケース用フォールバック
   - `Ctrl+S` (保存) / `Ctrl+O` (フォルダを開く)

3. **UI レイアウト & ワークスペース（VS Code風）**
   - カスタムタイトルバー（フレームレスウィンドウ）
   - 2セクション構成の左サイドバー
     - 開いているエディタ（複数タブ表示・ダーティ状態追跡）
     - ワークスペース（ファイル/フォルダツリー）
   - アクションボタン（すべて保存・すべて閉じる・更新等）のホバー表示
   - メインエディター領域
